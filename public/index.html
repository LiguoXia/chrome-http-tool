使用说明

      

        
      

    

    

      

        
上手快速上手

        

          ① 左侧 + 新建场景，场景间配置互相独立；

          ② 顶栏切换环境，每个环境有独立的请求头、全局变量与请求选项；

          ③ 新增接口或从 curl 导入，点「发送」立即调试；

          ④ 右键接口卡片可复制为 cmd / bash curl 命令；

          ⑤ 轮询面板可单独配置、收起/展开。
        

      

      

        
变量全局变量 {{变量名}}

        
在全局设置中定义变量后，接口的 URL、请求头、参数内容中都可以用 {{变量名}} 引用，发送前自动替换。切换环境后引用同一变量名、取不同值。

        
定义：baseUrl = https://api.example.com/v1
URL：{{baseUrl}}/resources/{{resourceId}}
参数：{ "ownerId": "{{userId}}" }

      

      

        
JSONJSON 请求体

        
填写合法的 JSON 对象，请求时以 application/json 发送到请求体，支持 {{变量名}} 引用。

        
{
  "name": "示例数据",
  "ownerId": "{{userId}}"
}

      

      

        
FORM表单键值对

        
填写 JSON 键值对，请求时自动编码为 application/x-www-form-urlencoded 表单提交。

        
{ "userId": "{{userId}}", "type": "fast" }

      

      

        
QUERYURL 查询参数

        
填写 JSON 键值对，请求时自动拼接到接口地址后（?a=1&b=2）。GET 请求默认按此方式处理。

        
{ "page": 1, "size": 10 }

      

      

        
RAW原始文本原样发送

        
参数内容将原样作为请求体发送，可填写任意文本（XML、纯文本等），支持 {{变量名}} 引用。

        
<payload>
  <id>{{resourceId}}</id>
</payload>
